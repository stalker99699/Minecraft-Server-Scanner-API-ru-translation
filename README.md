# Minecraft-Server-Scanner-API-ru-translation
API для получения данных из моей базы данных серверов. Серверы находятся [сканером-ru](https://github.com/stalker99699/Minecraft-Server-Scanner-Discord-Bot-ru-translation), обновляются и записываются в базу данных [повторным сканером](https://github.com/kgurchiek/Minecraft-Server-Rescanner). Этот API используется в https://github.com/stalker99699/Minecraft-Server-Scanner-Discord-Bot-ru-translation
